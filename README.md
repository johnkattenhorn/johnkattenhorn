### What I'm building now

Mostly tooling for working with AI agents. The criteria I'd used for years to
make decisions stopped holding somewhere around 2024, and I'd rather find out
where the new ones are by building than by reading about it.

* **[omawrite](https://github.com/johnkattenhorn/omawrite)** is a fork of the
  Markdown editor Omarchy ships. 21 upstream pull requests reconciled, plus
  image paste and a D-Bus command line, so an agent can edit a file while it's
  open in front of me. The
  [decisions log](https://github.com/johnkattenhorn/omawrite/blob/custom/docs/DECISIONS.md)
  is the part worth reading.
* **[mcp-bamboohr-plus](https://github.com/johnkattenhorn/mcp-bamboohr-plus)**,
  **[docmost-mcp](https://github.com/johnkattenhorn/docmost-mcp)** and
  **[cronometer-core](https://github.com/johnkattenhorn/cronometer-core)** are
  MCP servers, so agents can reach the systems I actually use rather than the
  ones that happen to have integrations.
